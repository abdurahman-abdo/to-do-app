Here's a feature list to think through, roughly ordered from "must have" to "nice stretch goals":

**Core (build these first)**
- Add a task
- List all tasks
- Mark a task as done
- Delete a task
- Persist tasks between runs (so they don't vanish when you close the terminal)

**Makes it actually useful day-to-day**
- Due dates
- Priority levels (high/medium/low)
- Categories or tags (work, personal, etc.)
- Sort/filter (e.g. show only pending, show only high priority, sort by due date)
- Edit an existing task (not just delete-and-recreate)

**Polish**
- Color-coded output (overdue tasks in red, done tasks greyed out, etc.)
- Search tasks by keyword
- Undo last action
- Recurring tasks (e.g. "every Monday")
- A count/summary line (e.g. "3 pending, 1 overdue, 5 done")

**Stretch / ambitious**
- Subtasks or task dependencies
- Export to CSV
- Reminders/notifications
- Multiple to-do lists or projects
- A config file for things like default sort order or file location
